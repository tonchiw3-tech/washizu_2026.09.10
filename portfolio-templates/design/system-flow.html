3 画面遷移フロー

全体の画面遷移図 必須
トップページから各主要情報へ直接進み、おすすめプランの確認や予約まで行うユーザーフロー
【トップページ】
  ├─「香りづくり体験」→【香りづくり体験ページ】
  │
  ├─「おすすめの過ごし方」→【条件選択画面】
  │                              │「おすすめを見る」
  │                              ▼
  │                         【おすすめプラン一覧画面】
  │                              │「詳細を見る」
  │                              ▼
  │                         【プラン詳細画面】
  │                              ├─「体験内容を見る」→【香りづくり体験ページ】
  │                              ├─「アクセスを見る」→【アクセス・周辺情報ページ】
  │                              ├─「FAQを見る」→【FAQページ】
  │                              └─「空き状況を見る」→【予約案内ページ】
  │
  ├─「アクセス」→【アクセス・周辺情報ページ】
  │
  ├─「FAQ」→【FAQページ】
  │
  └─「予約」→【予約案内ページ】
                    │「予約する」
                    ▼
               【既存予約ページ】
               （じゃらん等の外部予約サイト）
画面遷移のポイント
ユーザーが予約判断に必要な情報へ迷わず進めるようにする
起点 操作 遷移先
トップページ 香りづくり体験 香りづくり体験ページ
トップページ おすすめの過ごし方 条件選択画面
トップページ アクセス アクセス・周辺情報ページ
トップページ FAQ FAQページ
トップページ 予約 予約案内ページ
条件選択画面 おすすめを見る おすすめプラン一覧画面
おすすめプラン一覧画面 詳細を見る プラン詳細画面
プラン詳細画面 体験内容を見る／アクセスを見る／FAQを見る 各情報ページ
プラン詳細画面 空き状況を見る 予約案内ページ
予約案内ページ 予約する 既存予約ページ（外部予約サイト）
