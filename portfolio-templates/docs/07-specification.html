1 システム概要

対象システム

香作（こうさく）／香作室

inimuの香水づくり体験を紹介し、利用者が希望日・時間・人数などを入力して予約内容を確認できるWebアプリケーションです。旧計画「旅香 - TABIKA -」の観光プラン検索、天候判定、外部API連携は対象外とします。

目的
  • 香水づくり体験の内容・料金・開催時間を分かりやすく伝える。
  • 予約に必要な情報を入力し、確定前に確認できるようにする。
  • 予約情報をブラウザ内に保存し、スタッフ画面で一覧確認できるようにする。
システム構成
利用者（PC・スマートフォン）
          │
          ▼
Webブラウザ ── HTML / CSS / JavaScript
          │
          └── localStorage（予約データ保存）

Spring Boot・MySQL・天気API・外部予約APIとの連携は実装対象外です。

4 機能詳細

F-002 体験内容

通常は12種類の香料から4種類を選んでブレンドします。完成した香水10mlと、選んだ香料各10mlを持ち帰ります。体験時間は約60分、料金は1人5,500円として表示します。

F-003～F-005 予約処理
  1. 希望日、希望時間、人数、氏名、メールアドレス、年代、初回／リピーターを入力する。
  2. 希望日は土・日・祝として扱い、平日が選択された場合はメッセージを表示する。
  3. 確認画面で人数分の料金（1人5,500円）を表示する。
  4. 確定時に「KS-」から始まる予約番号を発行し、予約情報をlocalStorageへ保存する。

予約データはブラウザ単位の保存で、サーバーや外部予約サービスへ送信しません。

F-006 スタッフ用一覧

保存された予約を日付・時間順に表示します。予約件数を表示し、ステータスを「受付済み」「確認済み」「キャンセル」から変更できます。

現実装では認証処理を行っていないため、公開環境での業務利用には使用しません。
