1 システム概要

システムの目的 必須
このシステムが解決する課題と提供する価値

利用者の予定や状況から、自分に合った浅草の香りづくり体験を見つけ、予約まで進めるWebシステムです。

システム構成図 必須
フロントエンド ↔ バックエンド ↔ データベースの関係を図示

   ↓
【フロントエンド】

Thymeleaf
   ↓
【バックエンド】
Spring Boot
Controller
   ↓
Service
   ↓
Repository
   ↓
【データベース】
MySQL / H2

戻り方向：
DB → Repository → Service → Controller → ブラウザ

3 画面遷移図

画面遷移図 必須
トップページから各主要情報へ直接進み、おすすめプランの確認や予約まで行う導線
【トップページ】
  ├─「香りづくり体験」→【香りづくり体験ページ】
  │
  ├─「おすすめの過ごし方」→【条件選択画面】
  │                              │「おすすめを見る」
  │                              ▼
  │                         【おすすめプラン一覧画面】
  │                              │「詳細を見る」
  │                              ▼
  │                         【プラン詳細画面】
  │                              ├─「体験内容を見る」→【香りづくり体験ページ】
  │                              ├─「アクセスを見る」→【アクセス・周辺情報ページ】
  │                              ├─「FAQを見る」→【FAQページ】
  │                              └─「空き状況を見る」→【予約案内ページ】
  │
  ├─「アクセス」→【アクセス・周辺情報ページ】
  │
  ├─「FAQ」→【FAQページ】
  │
  └─「予約」→【予約案内ページ】
                    │「予約する」
                    ▼
               【既存予約ページ】
               （じゃらん等の外部予約サイト）
画面別の役割
各画面でユーザーが判断・実行する内容
画面 主な役割 次の導線
トップページ サービスの概要と香りづくり体験の魅力を伝える 香りづくり体験／おすすめの過ごし方／アクセス／FAQ／予約
条件選択画面 時間・出発地・天候・利用シーンなどの条件を選ぶ おすすめを見る
おすすめプラン一覧画面 条件に合う過ごし方やモデルコースを一覧表示する 詳細を見る
プラン詳細画面 モデルコース、所要時間、移動、香りづくり体験を確認する 体験内容・アクセス・FAQ・空き状況
予約案内ページ 空き状況の確認と外部予約サイトへの案内を行う 予約する
既存予約ページ じゃらん等の外部予約サイトで予約を完了する 外部サイト
