本サイトでは、最初から香りづくりを目的としている利用者だけでなく、浅草観光、街歩き、雨による予定変更、イベント前後、新幹線などでの移動前後、自然の香りへの興味など、利用者の状況や好みを入口として香りづくり体験を発見できる構成とする。

トップページでは、香りづくり体験の実績や内容を伝えたうえで、「あなたにぴったりプラン」から自分に近い状況や興味を選択できるようにする。

さらに、FAQ・アクセス・空き状況確認・予約CTAまでを一続きに配置し、

興味を持つ → 安心する → 体験を理解する → 自分に合うプランを見つける → 不安を解消する → 予約する

という流れを構築する。

3 ユーザーフロー

メインシナリオ

浅草や東京を訪れた利用者が、観光だけではなく、思い出に残る体験も楽しみたいと考え、旅香のサイトを訪れる。

トップページのメインビジュアルで、

「浅草で、自分だけの日本の香りをつくる旅。」

というコンセプトを知る。

続いて、予約実績・参加実績・26種類の香りから選べることなどを確認し、初めてでも参加しやすい体験であることを知る。

「香りづくり体験」で、

01 選ぶ → 02 試す → 03 調合する → 04 持ち帰る

という体験の流れを確認する。

その後、「あなたにぴったりプラン」から、自分の予定や興味に近いプランを選択する。

必要に応じてFAQやアクセス情報を確認し、疑問や移動に関する不安を解消する。

体験してみたいと感じた利用者は、「空き状況を見る」「ワークショップを予約する」から既存予約サービスへ進む。

流れ： トップ → 安心材料 → 香りづくり体験 → あなたにぴったりプラン → FAQ・アクセス → 空き状況を見る → 予約

サブシナリオ1：雨の日・予定変更

上野動物園などの屋外観光を予定していた利用者が、雨天のため予定を変更し、室内で楽しめる体験を探す。

旅香のトップページにある「あなたにぴったりプラン」から、「雨の日」を選択する。

そこで、天候に左右されにくい室内体験としてinimuの香りづくりを知る。

「香りづくり体験」で内容や所要時間を確認し、アクセス情報から現在地からinimuまでの移動を確認する。

予定に組み込めると判断した場合、「空き状況を見る」「ワークショップを予約する」から既存予約サービスへ進む。

流れ： 雨で予定変更 → 雨の日プラン → 香りづくり体験 → アクセス確認 → 空き状況を見る → 予約

サブシナリオ2：イベント前後

東京ドームなどでライブ・イベントに参加する利用者が、イベント前後に2〜3時間程度の時間がある。

旅香の「あなたにぴったりプラン」から、「イベント前後」を選択する。

イベント前後の時間を利用して浅草で香りづくりを楽しめることを知る。

香りづくり体験の内容や所要時間を確認し、アクセス情報から次の予定までの移動を検討する。

予定に無理なく組み込める場合、「空き状況を見る」から予約へ進む。

流れ： イベント前後の時間 → イベント前後プラン → 香りづくり体験 → アクセス確認 → 空き状況を見る → 予約

サブシナリオ3：移動前後

新幹線を利用して東京を訪れた利用者が、東京到着後または出発前に楽しめる体験を探す。

旅香の「あなたにぴったりプラン」から、「移動前後」を選択する。

東京駅から浅草へ移動し、香りづくり体験を予定に組み込めることを知る。

体験時間やアクセスを確認し、時間に余裕がある場合は「空き状況を見る」から予約へ進む。

流れ： 東京駅・新幹線 → 移動前後プラン → 香りづくり体験 → アクセス確認 → 空き状況を見る → 予約

サブシナリオ4：自然の香りが好き

花や木、草、果実など、自然を感じる香りが好きな利用者が、自分の好みに合う香りづくり体験を探す。

旅香のサイトを訪れ、「あなたにぴったりプラン」から、「自然の香りが好き」を選択する。

そこで、26種類の香りの中から気になる香りを選び、香りの違いを試しながら、自分好みの組み合わせを見つけられることを知る。

「香りづくり体験」で、選ぶ・試す・調合する・持ち帰るという流れや所要時間を確認する。

自分の好きな香りをもとにオリジナルの香りづくりを楽しめると感じた場合、「空き状況を見る」「ワークショップを予約する」から既存予約サービスへ進む。

流れ： 自然の香りが好き → 自然の香りプラン → 香りづくり体験 → 空き状況を見る → 予約

サブシナリオ5：浅草観光

浅草寺や仲見世などを観光している利用者が、「見るだけではなく、浅草で何か体験もしたい」と考える。

「あなたにぴったりプラン」から、「浅草観光」を選択する。

浅草観光の途中に香りづくり体験を組み込めることを知り、体験内容・所要時間・アクセスを確認する。

観光予定に組み込めると判断した場合、「空き状況を見る」から予約へ進む。

流れ： 浅草観光 → 浅草観光プラン → 香りづくり体験 → アクセス確認 → 空き状況を見る → 予約

予約導線

今回のサイトでは、独立した /booking ページは設けず、

「空き状況を見る」

「ワークショップを予約する」

というボタンから既存予約サービスへ直接遷移する。

そのため、以前の /booking は削除する。

本サイトの導線まとめ

旅香では、ユーザーに最初から「香水づくり」を探してもらうのではなく、

「今の自分の予定や好みに合うものを選ぶ」

ことを入口とする。

「あなたにぴったりプラン」は、

浅草観光 / 街歩き / 雨の日 / イベント前後 / 移動前後 / 自然の香りが好き

の6つに分類する。

利用者が自分に近い入口を選び、香りづくり体験の内容を知り、FAQやアクセスで不安を解消したうえで予約へ進めるサイト構成とする。
