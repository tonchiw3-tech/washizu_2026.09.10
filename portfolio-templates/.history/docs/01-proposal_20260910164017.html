1 プロジェクト概要

サービス名 必須
制作するWebサービスの名前

旅香 - TABIKA -

コンセプト 必須
サービスを一言で表す説明（キャッチコピー＋1〜2文の説明）

浅草で、自分だけの日本の香りをつくる旅。

旅香 - TABIKA - は、香水づくりを最初から目的として検索している人だけでなく、「浅草で何をしよう」「少し時間が空いた」「雨で予定が変わった」など、その時の予定や状況からinimuの香りづくり体験を発見できるWebサービスである。

浅草を含む台東地域は、江戸時代から多くの職人が集まり、ものづくりの技術や文化が受け継がれてきた地域である。旅香 - TABIKA - では、こうした「ものづくりのまち・浅草」という背景と、inimuの香りづくり体験を結びつける。

既に魅力のあるinimuのワークショップを新しく作り直すのではなく、浅草観光や東京滞在の予定に組み込みやすい体験として見せ、発見から予約までをつなぐ新しいWeb導線を構築する。

ターゲットユーザー 必須
このサービスを使う主なユーザー像（概要レベル）

主なターゲット

浅草観光を楽しむ、または東京滞在中に思い出に残る体験を探している20〜40代の国内外来訪者。

特に、次のようなユーザーを想定する。

  • 浅草で観光だけでなく、体験型の思い出を作りたい人
  • 一人でも、友人やパートナーとでも、旅の記憶に残る体験を楽しみたい人
  • イベント前後の空き時間を、自分のペースで香りと向き合う時間にしたい人
  • 自分だけのものを作って持ち帰りたい人
  • 日本のものづくりや文化に触れたい人
  • 観光中に1〜3時間程度の空き時間ができた人
  • 雨天によって観光予定を変更し、室内で楽しめる体験を探している人

イベント参加者だけを対象とするのではなく、浅草観光・東京滞在中に生じるさまざまな状況の一つとして「イベント前後の空き時間」を位置づける。

また、一人で行動する利用者に対しても、単なる「時間つぶし」ではなく、自分の感覚で香りを選び、自分のためのものをつくる時間として体験価値を伝える。

2 背景と課題

市場の現状 必須
このサービスが存在する市場の現状と課題

香水・フレグランス市場では、商品を購入するだけでなく、自分で香りを選ぶ・調合する・名前を付けるなどの体験型サービスが提供されている。

競合では、MY ONLY FRAGRANCE、THE FLAVOR DESIGN、FINCA、OSAJIなどが、オーダーメイド香水や香りづくり体験を展開している。

競合の多くは、香りを選ぶ → 試す → 調合する → 名前やラベルを付ける → 持ち帰るという体験を提供しており、「自分だけの香りを作ること」そのものを来店目的としている。さらに一部の競合では、レシピ保存やECでの再購入など、体験後につながる仕組みも確認できる。

一方、inimuにも既に香りづくり体験としての実績がある。2025年3月〜2026年2月のワークショップ実績では、予約確定539件、参加人数1,157人、予約確定分請求金額約558万円となっており、香りづくり体験そのものへの需要は存在している。

また、inimuでは26種から香りを選ぶ香水づくりワークショップが提供されている。しかし、確認できるワークショップの予約経路はじゃらんnetが100％であり、自社WebやSNSなどから体験を発見し、予約へ進んだ利用者については十分に把握できていない。

さらに、浅草には観光地としての魅力だけでなく、ものづくりのまちとしての歴史的背景がある。浅草寺周辺には古くから職人が集まり、江戸時代の都市の発展とともに、浅草や上野を含む現在の台東区域には多くの職人や商人が移り住んだ。

現在も台東区では、江戸切子、江戸木版画、東京銀器、東京三味線、桐工芸など、さまざまな伝統工芸が受け継がれている。この背景から、浅草は単に「見る観光地」としてだけでなく、「ものづくりに触れる・体験する場所」としても発信できる地域である。

inimuの香りづくり体験も、こうした浅草のものづくり文化と親和性が高い。そのため、今回の課題はワークショップ自体の魅力を新しく作ることではなく、既にある魅力的な体験を、浅草らしいものづくり体験として、香水づくりを最初から目的としていない人にも発見してもらうWeb導線を作ることだと考える。

利用者は必ずしも「香水を作りたい」と検索するとは限らない。「浅草で何をしよう」「2時間くらい時間が空いた」「一人で楽しめる場所はないかな」「雨だから室内で楽しみたい」「イベント前後に観光できる時間がある」「東京旅行で思い出に残ることをしたい」「日本らしいものづくりを体験したい」といった状況から、その日の過ごし方を探している可能性がある。

そこで、ワークショップ単体を紹介するだけでなく、利用者の予定・時間・天候・興味・過ごし方などを入口として香りづくり体験を提案するWeb導線が必要である。

解決すべき課題 必須
本プロジェクトで解決を目指す具体的な課題（3つ程度）

1. 香水づくりを目的としていない潜在顧客に体験の存在が届いていない

現在は、「浅草 香水作り」「香水 ワークショップ」など、香水づくりを自ら検索する人には体験が届く可能性がある。

一方、浅草で何をするか探している人、東京旅行で思い出になる体験を探している人、一人でも楽しめる体験を探している人、日本のものづくりを体験したい人、イベント前後に観光できる時間がある人からは、inimuのワークショップが候補として発見されにくい可能性がある。

そのため、「香水づくり」という商品・サービス起点ではなく、利用者の目的や状況から体験を発見できるWeb導線を作る必要がある。

2. 観光中に生まれる「空き時間」を体験予約につなげられていない

旅行や観光では、食事まで時間がある、次の観光予定まで2時間空いた、一人で自由に過ごせる時間ができた、イベント前後に観光できる時間がある、当初の予定が変更になったなど、「次に何をするか決まっていない時間」が生まれる場合がある。

しかし現在は、このような時間に対して、inimuの香りづくり体験を「今からできる選択肢」として提案するWeb導線が十分ではない。

そのため、「2時間でできる」「半日で楽しめる」「一人でも自分のペースで楽しめる」「浅草観光に組み込める」など、利用可能な時間や過ごし方から体験を発見できる仕組みを設ける。

特に、一人旅や一人でイベントに参加している人に対しては、「イベント前後の空き時間を、自分のペースで香りと向き合う時間にする」という過ごし方を提案する。イベント参加者についても主な対象に限定せず、空き時間が発生する利用シーンの一例として扱う。

3. 「ものづくりのまち・浅草」と香りづくり体験のつながりが十分に伝わっていない

浅草を含む台東地域には、江戸時代から職人やものづくりの文化が受け継がれてきた歴史がある。一方、観光客にとって浅草は、浅草寺、雷門、食べ歩きなどのイメージが先行し、「自分でものをつくる場所」としての魅力まで十分に認識されていない可能性がある。

inimuには、自分で香りを選び、組み合わせ、自分だけの香りを完成させるという「ものづくり体験」がある。そのため、単に「浅草で香水が作れる」と発信するのではなく、「ものづくりの文化が息づく浅草で、自分だけの香りをつくる」というストーリーとして伝える必要がある。

4. 天候や予定変更時に選ばれる室内体験としての認知が不足している

浅草・上野などで観光している途中に雨が降った場合、屋外中心の観光予定を変更し、「近くで室内でできること」を探す行動が想定される。

inimuのワークショップは室内で楽しめる体験であるため、このような状況でも選択肢になり得る。しかし、「浅草 雨の日」「東京 雨の日 体験」「浅草 室内 アクティビティ」などの利用状況から香りづくり体験へつなぐ導線は十分ではない。

そのため、天候や予定変更を入口として、「雨の日でも楽しめる浅草のものづくり体験」として発見してもらう導線を構築する。

3 提案するソリューション

サービスの特長 必須
競合と差別化するサービスの特長を3つ

1. 「香水を作りたい人」以外にも届く利用シーン別Web導線

競合する香りづくりサービスでは、「自分だけの香りを作る」「オリジナル香水を作る」など、体験そのものを目的とした訴求が多く見られる。

旅香 - TABIKA - では、香水づくりを最初から探している人だけでなく、浅草で何をするか探している、旅の思い出になる体験をしたい、日本らしいものづくりを体験したい、一人でも楽しめる体験を探している、2〜3時間の空き時間がある、雨の日にできることを探している、イベント前後に観光できる時間がある、といった利用者側の状況を入口としてinimuへつなげる。

これにより、「香水づくりを探している人を待つ」のではなく、「浅草で体験を探している人に香りづくりを提案する」Web導線を構築する。

2. その日の予定や空き時間に合わせて「過ごし方」まで提案する

旅香 - TABIKA - では、ワークショップ単体を紹介するのではなく、その日の予定や興味に香りづくりをどのように組み込めるかまで提案する。

例えば、次のような過ごし方を提示する。

  • 浅草寺 → ランチ → 香りづくり → カフェ
  • 日本のものづくりを楽しみたい → 浅草散策 → 香りづくり
  • 2時間の空き時間 → 香りづくり → 次の予定へ
  • 一人旅の自由時間 → 自分のペースで香りづくり
  • イベント前後の空き時間 → 浅草観光 → 香りづくり → 次の予定へ
  • 雨天 → 屋外観光から室内の香りづくりへ変更

利用シーンを観光 / ものづくり / 空き時間 / 一人時間 / イベント / 雨天の6つに分け、それぞれ異なる目的から香りづくり体験へつなげる。イベントは主軸ではなく、東京滞在中に生まれる空き時間の一例として扱う。

また、一人で利用する場合も「時間をつぶす場所」としてではなく、「自分のペースで香りを選び、自分の感覚と向き合う時間」として体験価値を伝える。これにより、利用者はワークショップを単独の予定として考えるのではなく、東京で過ごす1日の中に組み込みやすくなる。

3. 「ものづくりのまち・浅草」で新しいものづくり体験を提案する

浅草を含む台東地域は、江戸時代から職人が集まり、さまざまなものづくりの技術が育まれてきた地域である。現在も、伝統工芸品や職人の技術が受け継がれ、ものづくりを体験・見学できる工房も存在している。

旅香 - TABIKA - では、この浅草の歴史的背景を、inimuの香りづくり体験と結びつける。つまり、「昔からものをつくる文化がある浅草で、現代の新しいものづくりとして自分だけの香りをつくる」という価値を提案する。

これにより、inimuを単なる香水づくりの店舗として紹介するのではなく、浅草のものづくり文化を現代的に体験できる場所の一つとして伝える。

4. 浅草・日本文化・旅の記憶を「香りとして持ち帰る」

inimuは、浅草で「香りを作る、ものを作る、繋がりを作る」という考え方を持つ体験型店舗であり、26種から香りを選ぶ香水づくりワークショップを提供している。

また、運営会社であるキャライノベイトは、日本の地域・伝統・文化・ものづくりの背景を香りを通じて伝えることを重視している。

旅香 - TABIKA - では、この企業独自の価値と浅草のものづくり文化を活かし、「ものづくりのまち・浅草で、旅の記憶を自分だけの香りとしてつくり、持ち帰る」という体験価値として訴求する。

競合の「自分だけの香りづくり」に加えて、浅草 × ものづくり文化 × 日本文化 × 香り × 旅の思い出まで一体化して伝えることで、inimuならではの価値を表現する。

4 制作範囲

Webサイト（フロントエンド）の範囲 必須
制作するWebサイトのページ一覧と概要

「旅香 - TABIKA -」では、浅草観光・イベント前後・雨天時など、ユーザーの状況からinimuの香りづくりワークショップを発見し、予約へ進めるWebサイトを制作する。

1. トップページ

「浅草で何する？」「イベントまで時間がある」「雨の日に楽しみたい」など、ユーザーの状況から目的に合ったページへ進める入口。旅香 - TABIKA - のコンセプトや香りづくり体験の魅力も紹介する。

2. 香りづくり体験紹介ページ

inimuのワークショップ内容、体験時間、香りを選んで作る流れ、完成品、料金、参加方法など、予約前に知りたい情報を分かりやすく掲載する。

3. 浅草観光モデルコースページ

浅草寺・ランチ・カフェ・香りづくりなどを組み合わせ、「浅草で半日・1日をどう過ごすか」を提案する。

4. イベント前後モデルコースページ

東京ドームや両国国技館などへの来場者を想定し、「グッズ購入→ランチ→香りづくり→イベント」や「ライブ翌日→浅草→香りづくり→帰宅」など、イベント前後の空き時間を活用したプランを紹介する。

5. 雨の日おすすめページ

浅草・上野周辺で雨天になった観光客に向けて、室内で楽しめる香りづくり体験としてinimuを紹介する。予定変更時でも利用しやすいことを伝える。

6. アクセス・周辺情報ページ

inimuへのアクセスに加え、浅草駅・上野・両国・東京ドームなど主要地点からの移動目安を掲載し、観光やイベント予定に組み込みやすくする。

7. FAQページ

所要時間、料金、予約方法、初心者でも参加できるか、人数、持ち物、当日の流れなど、予約前の不安や疑問を解消する。

8. 予約案内ページ／予約CTA

各ページから「空き状況を見る」「ワークショップを予約する」へ進める導線を設置し、既存の予約サービスへつなげる。

サイト全体の役割

本サイトでは、単にワークショップの情報を掲載するのではなく、次の流れを作る。

「今の予定・状況から体験を探す」→「自分に合った過ごし方を知る」→「香りづくりに興味を持つ」→「予約する」

これにより、「香水づくり」を最初から検索している人だけでなく、浅草観光、イベント前後の空き時間、雨天時の予定変更などをきっかけに、inimuを発見できる新しいWeb導線を構築する。

Webアプリケーション（サーバーサイド）の範囲 必須
制作するWebアプリケーションの機能概要

「旅香 - TABIKA -」では、ユーザーの予定や状況に応じて、inimuの香りづくり体験を含むおすすめの過ごし方を提案するWebアプリケーションを制作する。

1. 利用シーン選択・おすすめプラン表示機能

ユーザーが「浅草観光」「イベント前」「イベント翌日」「雨の日」などの利用シーンを選択すると、その条件に合ったおすすめモデルコースを表示する。

例えば、「東京ドームで17時からライブ」という予定に対して、グッズ購入、浅草への移動、ランチ、香りづくり体験、東京ドームへの移動という過ごし方を提案する。

2. 空き時間に合わせたプラン検索機能

ユーザーが「2時間」「3時間」「半日」など、利用できる時間を入力・選択すると、その時間内で体験できるモデルコースを表示する。

香りづくりワークショップの所要時間や移動時間を考慮し、無理のないプランを提案する。

3. イベント会場別プラン表示機能

東京ドーム、両国国技館など、浅草周辺からアクセスしやすいイベント会場を登録し、会場ごとにおすすめのモデルコースを表示する。

イベント前だけでなく、「ライブ翌日に浅草を楽しんでから帰る」といったプランも選択できるようにする。

4. 天候に応じたおすすめ表示機能

天気情報を取得し、雨天時には「雨の日におすすめ」として、室内で楽しめるinimuの香りづくり体験を優先して表示する。

これにより、上野・浅草などを観光中に予定変更が必要になったユーザーにも、新しい過ごし方を提案する。

5. ワークショップ予約への導線機能

おすすめプランやワークショップ紹介ページから、「空き状況を見る」「ワークショップを予約する」ボタンを設置し、既存の予約サービスへ遷移できるようにする。

本制作では予約システムそのものを新規開発するのではなく、既存予約サービスへの導線を構築する。

Webアプリケーション全体の流れ

ユーザーの状況を選択する
↓
イベント会場・空き時間・天候などの条件を入力する
↓
条件に合ったモデルコースを表示する
↓
inimuの香りづくり体験を知る
↓
既存の予約ページへ進む

これにより、香水づくりを最初から目的としていないユーザーにも、現在の予定や状況に合わせてinimuのワークショップを提案し、予約につなげるWebアプリケーションを構築する。
