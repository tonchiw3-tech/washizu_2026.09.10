# 旅香 - TABIKA -

## 概要

「浅草で、自分だけの日本の香りをつくる旅。」をコンセプトに、浅草観光や東京滞在中の予定に合わせて、香りづくり体験を見つけられるWebサイトです。

香水づくりを目的に検索している人だけでなく、「浅草で何をしよう」「少し時間が空いた」「雨で予定が変わった」といった状況にいる人にも、inimuの体験を知ってもらい、予約につなげる新しいWeb導線を提案しました。

## 制作目的

ワークショップの予約数低迷と、新しいWeb導線が必要という課題に対し、香りづくりを目的にしていないユーザーにも体験を届ける入口をつくることを目的としました。

## ターゲット

浅草観光や東京滞在中に、思い出に残る体験を探している20〜40代の国内外来訪者を想定しています。

- 浅草観光中の人
- 2〜3時間程度の空き時間がある人
- 一人で自分のペースを楽しみたい人
- ライブやイベントの前後に時間がある人
- 雨天時でも楽しめる室内体験を探している人
- 日本らしいものづくり体験を探している人

## 課題

マーケットリサーチや競合分析を通して、ワークショップ自体の魅力だけでなく、「どのように見つけてもらうか」という導線に課題があると考えました。

- 香りづくりを検索していない人には届きにくい
- 浅草観光と香りづくり体験のつながりが分かりにくい
- 空き時間やイベント前後など、利用シーンから探せない
- 雨の日に楽しめる体験として認知されにくい
- 体験を知ってから予約までの導線が弱い

## 解決方法

ユーザーの目的ではなく、「今の状況」から体験を探せる構成にしました。

「浅草観光」「ものづくり体験」「空き時間」「一人時間」「イベント前後」「雨の日」を主な入口として設け、おすすめの過ごし方から香りづくり体験へ自然に誘導します。体験内容、浅草のものづくり文化、アクセスや周辺情報を確認したうえで予約へ進める流れを設計しました。

### 想定導線

浅草で何をするか探す → 自分に合った過ごし方を知る → 香りづくり体験を知る → 空き状況を見る → 予約へ進む

ペルソナや利用シーンを起点に各ページの役割を整理し、企画提案から予約まで一貫した導線になるように設計しています。

## 工夫した点

- 香りづくりを目的にしていない人にも届くよう、利用シーン別の入口を設計
