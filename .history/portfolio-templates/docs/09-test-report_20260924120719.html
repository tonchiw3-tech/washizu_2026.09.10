1 テスト計画

テスト対象・範囲 必須
テストの対象となる機能・画面と、テストの種類

本テストでは、Webサービス「旅香 - TABIKA -」のフロントエンドについて、画面表示・ページ遷移・ボタン操作・レスポンシブ表示などが設計どおりに動作するかを確認する。

本サイトは、浅草観光・ものづくり・空き時間・一人時間・イベント前後・雨の日など、利用者の状況からinimuの香りづくり体験を発見し、既存の予約サービスへ進んでもらうことを目的としている。

テスト対象：トップページ、香りづくり体験紹介、利用シーン別コンテンツ、浅草観光・おすすめの過ごし方、アクセス・周辺情報、FAQ、予約CTA、ヘッダー・ナビゲーション、フッター、外部リンク、Googleマップ、PC・スマートフォン表示。

テスト種別：機能テスト、画面テスト、レスポンシブテスト、リンクテスト、基本的なセキュリティ確認。

テスト環境：Windows 11、Google Chrome / Microsoft Edge / Firefox、スマートフォンのChrome / Safari、PC 1440px前後、スマートフォン390px前後、GitHub Pages。

テスト期間：2026年9月24日 ～ 2026年10月1日

重大度の基準

高：ページが表示できない、予約導線が利用できないなど、サービスの目的に大きく影響するもの。

中：一部のボタンが動作しない、スマートフォンで表示が崩れるなど、利用に支障があるもの。

低：余白・文字サイズ・位置ずれなど、サービス利用自体には大きく影響しないもの。

確認 テスト実施時の確認ポイント

トップページ → 利用シーンを選ぶ → おすすめの過ごし方を知る → 香りづくり体験を見る → 空き状況を見る → 予約ページへ進む、という一連の流れが途中で途切れず利用できることを重点的に確認する。

特に「空き状況を見る」「ワークショップを予約する」は、本サイトの目的である予約導線に直接関係するため、PC・スマートフォンの両方で必ず確認する。
