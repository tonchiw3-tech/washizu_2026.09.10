本アプリでは、利用者が浅草観光やイベント前後のすき間時間を基点に、香りづくり体験を自然に体験計画へ組み込めるようにする。

各画面は、体験内容・おすすめの過ごし方・周辺情報・FAQ・予約導線を順に確認できる構成にし、予約画面からは既存予約サービスへ遷移する。

Spring Bootでは入力された条件を受け取り、おすすめプランを取得して一覧画面に表示する。利用者は気になるプランの詳細を確認し、inimuの香りづくり体験やアクセス情報を確認したうえで、既存の予約サービスへ進む。

予約機能そのものは新規開発せず、「空き状況を見る」「ワークショップを予約する」などの導線から既存予約ページへ遷移する構成とする。

3 ユーザーフロー

メインシナリオ 必須
ペルソナがサイトに訪問してから目的を達成するまでの動線（メインの行動パターン）

浅草観光を楽しんでいる利用者が、「見るだけでなく、思い出に残る体験もしたい」と考え、旅香のサイトを訪れる。

トップ画面で「浅草で、自分だけの香りをつくる旅。」というコンセプトを知り、inimuの香りづくり体験に興味を持つ。

「香りづくり体験」画面で、体験内容、香りづくりの流れ、料金、所要時間、完成品、浅草のものづくりとのつながりを確認する。

その後、「おすすめの過ごし方」画面で、浅草観光の中に香りづくり体験をどのように組み込めるかを確認する。

必要に応じて「アクセス・周辺情報」や「FAQ」を確認し、移動時間や予約前の疑問を解消する。

体験してみたいと感じた利用者は、「空き状況を見る」「ワークショップを予約する」から既存の予約サービスへ移動し、予約を行う。

流れ： トップ → 香りづくり体験 → おすすめの過ごし方 → アクセス・FAQ → 予約

サブシナリオ1：雨天による予定変更 任意
雨天によって屋外観光から室内体験へ予定を変更する行動パターン

上野動物園などの屋外観光を予定していた利用者が、雨天のため予定を変更し、室内で楽しめる体験を探す。

旅香のサイトを訪れ、「おすすめの過ごし方」から「雨の日・予定変更」を確認する。

そこで、雨の日でも楽しめる浅草の過ごし方として、inimuの香りづくり体験を知る。

「香りづくり体験」画面で、体験内容、所要時間、料金、完成品などを確認し、「アクセス・周辺情報」で上野周辺からの移動時間を確認する。

利用者は、自分の予定に組み込めると判断した場合、「空き状況を見る」「ワークショップを予約する」から既存予約ページへ進む。

流れ： 雨で予定変更 → おすすめの過ごし方 → 香りづくり体験 → アクセス確認 → 予約

サブシナリオ2：イベント前後のすき間時間 任意
ライブやイベントの合間に、短時間で楽しめる体験を探す行動パターン

東京でライブやイベントに参加する利用者が、開演まで2〜3時間程度のすき間時間があり、その時間に楽しめる体験を探す。

旅香のサイトを訪れ、「おすすめの過ごし方」から「ライブ・イベント前後」を確認する。

そこで、イベント前後のすき間時間に組み込みやすい過ごし方として、inimuの香りづくり体験を知る。

「香りづくり体験」画面で、体験内容、所要時間、料金、完成品などを確認し、「アクセス・周辺情報」で東京ドームや日本武道館、東京国際フォーラムなど、次の予定先までの移動時間を確認する。

利用者は、体験時間と移動時間を考えても開演時間に間に合うと判断した場合、「空き状況を見る」「ワークショップを予約する」から既存予約ページへ進む。

流れ： イベント前のすき間時間 → おすすめの過ごし方 → 香りづくり体験 → 会場までの移動時間を確認 → 予約
